### 🏢 Current Focus — Project Prabodh @ C-DAC, Patna

I'm currently interning at **C-DAC, Patna**, building **Prabodh** — an **AI-enabled Complaint Processing and Decision Support System** for government grievance handling.

- 📄 **Multi-channel intake:** Accepts complaints as PDFs or scanned images (typed letters, handwritten applications, multi-page documents) submitted via email or digitised from physical filings.
- 🔍 **OCR + document understanding:** Automatically extracts structured metadata — complainant name, address, date, subject, and reference numbers.
- 🧠 **AI summarisation & flagging:** Generates concise complaint summaries and raises attention flags for urgency, repeated grievances, or escalation risk.
- 🏛️ **Smart routing:** Recommends the appropriate department using a knowledge base of complaint-to-department mappings, with operator override.
- ✉️ **Auto-drafted communication:** Generates official letters from templates, pre-filled with complaint details and a unique diary/reference number.
- 🔗 **Contextual intelligence:** Maintains complainant profiles to detect and link repeated or related grievances over time.
- 📈 **Admin dashboard:** Visualises complaint volume, department-wise load, resolution status, and average processing time for administrative oversight.

**Goal:** Improve administrative efficiency, traceability, and turnaround time for public grievance redressal.
